Arcadia 是一款受silent hill影响的第一人称ps2复古风格的心理恐怖游戏。
你将在一件陈旧没有生气的房间中醒来，探索环境并且探明周遭诡异的真相来源。
你通过“对话”系统，可以在*内在*之中与自己的不同人格倾向交流，而不同的对话选项将影响故事的呈现与走向。

在*无名*与*无限*的恐惧之中，你会发现这压抑静谧之地的惨绝人寰的真相。
